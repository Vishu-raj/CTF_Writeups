# HackZero '26 CTF 🚩

This repository contains my participation proof, challenge documentation, and screenshots for the **HackZero '26 Capture The Flag (CTF)** event, hosted by VIT Bhopal in April 2026. 

## 🏆 Performance & Achievement
* **Global Rank:** 66th (out of 200+ participants)
* **Points Scored:** 2,620 points
* **Event Level:** National-Level Cybersecurity CTF (MythX: An Endgame Protocol)

## 🧠 Topics & Domains Explored
This CTF tested practical, hands-on ethical hacking skills across multiple domains. Key areas of focus included:
* **Web Exploitation:** Hunting for vulnerabilities like SQL Injection (SQLi), Cross-Site Scripting (XSS), IDOR, and Authentication flaws.
* **Cryptography & Steganography:** Decrypting ciphers and extracting hidden data from media files.
* **Digital Forensics:** Analyzing packet captures and memory dumps.
* **Reverse Engineering:** Decompiling binaries to understand application logic.
* **OSINT:** Open Source Intelligence gathering.
