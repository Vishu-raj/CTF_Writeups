# 🚩 CTF Writeups & Vulnerability Assessments

Welcome to my central repository for Capture The Flag (CTF) writeups and web exploitation documentation. This repository serves as a technical archive of my methodologies, thought processes, and practical execution in various national and university-level cybersecurity challenges.

## 📂 Repository Structure

The repository is organized by the specific CTF events I have participated in. Each directory contains detailed, step-by-step writeups, proof-of-concept (PoC) screenshots, and mitigation strategies.

* 📁 **CyberGeek_CTF_{IIIT_Allahabad}/** - Strategic writeups and tactical solutions detailing vulnerability exploitation methodologies applied during the CyberGeek CTF hosted by IIIT Allahabad.

* 📁 **Hack!tUp_CTF/** - Analytical breakdowns, proof-of-concept (PoC) development, and mitigation strategies for diverse cybersecurity challenges encountered during the Hack!tUp event. *(Feel free to add the host name here if there was one!)*

* 📁 **HackZero'26_CTF_{VIT_Bhopal}/** - Step-by-step documentation of challenges solved during the HackZero '26 CTF hosted by VIT Bhopal, featuring practical execution of web application security testing.

* 📁 **MTHX_CTF_{KIET_Group_of_Institutions}/** - Comprehensive technical archive from the National-Level MythX: An Endgame Protocol CTF hosted by KIET, highlighting advanced web exploitation and logic flaw identification.

## 🎯 Core Focus Areas

Through these writeups, I demonstrate practical, hands-on experience in identifying and exploiting web application vulnerabilities. My primary areas of focus include:

*   **Web Exploitation:** Bypassing authentication mechanisms and manipulating application logic.
*   **Vulnerability Assessment:** Deep-dive analysis to uncover hidden flaws.
*   **Targeted Vulnerabilities:** 
    *   Insecure Direct Object Reference (IDOR)
    *   SQL Injection (SQLi)
    *   Cross-Site Scripting (XSS)
    *   Authentication and Session Management Flaws

## 🛠️ Tools & Technologies

The methodologies detailed in these writeups utilize an offensive security toolkit within a **Kali Linux** environment, primarily leveraging:

*   **Burp Suite Professional:** For traffic interception, request manipulation, and vulnerability identification.
*   **OWASP ZAP:** For automated scanning and vulnerability assessment.
*   **Gobuster:** For aggressive directory and DNS reconnaissance.
*   **SQLMap:** For automated SQL injection and database takeover.
